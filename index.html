Respaldo Automático en Archivo

Elige un archivo en esta computadora (de preferencia en una carpeta sincronizada como OneDrive o Google Drive). El sistema lo actualizará automáticamente al terminar cada venta, anulación, devolución, cambio por garantía y corte de caja. Si se borran los datos del navegador, la información sigue en ese archivo y se recupera con "Importar / Restaurar". Disponible en Chrome o Edge de computadora.

Importar / Restaurar Copia de Seguridad

Exporta toda la base de datos local (inventario, historial completo de ventas del día, piezas, cortes de caja, retiros/ajustes y configuraciones) a un archivo .json estructurado con fecha y hora POS_Backup_YYYYMMDD_HHMMSS.json. Permite la sincronización remota y la recuperación ante actualizaciones o fallos.
